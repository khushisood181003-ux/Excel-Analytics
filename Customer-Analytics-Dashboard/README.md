# Customer Analytics Dashboard

## Project Overview

An Excel-based Customer Analytics Dashboard developed to analyze customer demographics, account balances, product usage, customer activity, and customer segments.

The project transforms raw customer data into meaningful business insights using Excel formulas, Pivot Tables, Pivot Charts, and interactive slicers.

## Project Objectives

- Analyze overall customer demographics
- Identify active and inactive customers
- Analyze customer account balances
- Understand customer distribution across age groups
- Analyze customer distribution by gender, occupation, region, and channel
- Identify different customer segments
- Present key business insights through an interactive dashboard

## Dashboard Analysis

The dashboard provides analysis of:

- Gender Distribution
- Customer Age Groups
- Customer Status
- Occupation-wise Average Account Balance
- Region-wise Average Account Balance
- Channel-wise Customer Distribution
- Customer Activity
- Credit Product Usage

## Business Insights

The dashboard highlights patterns such as:

- The 26–35 age group represents the largest customer segment.
- Dormant customers form the largest customer-status group.
- Entrepreneurs have the highest average account balance among occupations.
- X1 is the most frequently used customer channel.
- Customer activity and product usage can be analyzed interactively using slicers.

## Interactive Dashboard

The dashboard includes interactive slicers for:

- Gender
- Occupation
- Region
- Channel
- Customer Status

These filters allow users to explore customer segments dynamically and evaluate how different customer characteristics affect the analysis.
